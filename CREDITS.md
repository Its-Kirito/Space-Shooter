# 🎖️ Credits

This project is a personal, non-commercial game created for learning and fun. While all core design, programming, and logic were implemented by me, several visual and audio assets were sourced externally. Proper credit is given below.

---

## 🎮 Game & Code

- Designed and developed using **Python** and **Pygame**.
- [Background star animation code](space_bg_module.py) generated using **Gemini AI 2.5 Pro**.
- Game logic, user interfaces, and all integration were implemented manually.
